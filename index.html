JiraWay

LIVE DEMO

Most Jira tutorials explain the tool without ever making you use it — so I built JiraWay for people starting a new job or internship where Jira is already the standard. It's entirely client-side, no backend or signup beyond a name and email, so nothing stands between opening the link and starting. And it's one continuous ticket across all five modules, not a fresh demo each time, because that's how a ticket actually moves through a real sprint — created, updated, and closed, not reset for every lesson.

Go_Transit

LIVE DEMO

Waiting for a bus without knowing when it'll actually arrive wastes time — so I built Go_Transit for daily commuters: search a bus by number or stop, then watch it move live on a map with ETA, distance and speed. The positions are simulated along a real Coimbatore route, but I built the frontend to treat that feed exactly like real GPS data — so swapping in an actual GPS feed later wouldn't need the interface to change at all.
